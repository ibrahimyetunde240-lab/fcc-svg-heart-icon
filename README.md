# SVG Heart Icon

A simple HTML workshop completed as part of the freeCodeCamp Responsive Web Design curriculum.

## Overview

This project demonstrates how to create a scalable heart icon using SVG (Scalable Vector Graphics) in HTML.

## Technologies Used

- HTML5
- SVG

## What I Learned

- Creating SVG elements
- Using the `viewBox` attribute
- Drawing shapes with the `<path>` element
- Applying color using the `fill` attribute
